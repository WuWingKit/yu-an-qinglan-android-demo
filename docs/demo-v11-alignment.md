## 视觉语言

### 设计气质

关键词是安静、自然、可信、温和，不使用殡葬行业常见的深黑、浓金和沉重仪式感。页面以暖白为底，青绿承担品牌和主操作，花粉、浅蓝、浅黄用于区分服务，而不是制造高饱和装饰。

### 尺寸与排版

- 设计基准：`375 x 812dp`，主内容水平边距 `14dp`。
- 顶栏标题 `16sp / SemiBold`；页面大标题 `22sp / SemiBold`；区块标题 `17sp / SemiBold`；正文 `13-14sp`；元数据 `11-12sp`。
- 行高约 `1.3-1.6`；中文不使用负字距。
- 卡片主圆角 `16dp`，紧凑控件 `10dp`，大场景 `22dp`，胶囊按钮使用全圆角。
- 卡片内边距通常 `14dp`，页面区块间距 `12-14dp`，双列网格间距 `10dp`。
- 底部导航总高约 `78dp`，图标 `22dp`；Android 实现必须叠加系统导航栏安全区。
- 主按钮视觉高度约 `44-46dp`；Android 点击热区统一提升到至少 `48dp`。

## 关键演示流

1. 启动页进入首页，查看 Banner、四类服务入口、生命教育、活动与资讯。
2. 首页进入政策补贴，选择区县并提交本地预审，得到补贴拆分结果。
3. 安葬页在人类/宠物间切换，查看树葬详情、套餐和预约表单。
4. 追忆页创建纪念空间，进入独立纪念页，再展示 AI 伦理与素材选择。
5. 树洞入口展示双池隔离，再进入人间树洞完成写信和待审核反馈。
6. 我的页面展示素材销毁、树洞开关、适老模式和隐私权限。

## 审计发现

### 做得好的部分

- 五个一级 Tab 稳定，核心链路的当前位置清楚。
- 人类与宠物服务、纪念空间和树洞内容池均明确隔离。
- 政策预审结果用金额拆分和后续步骤建立可信度。
- AI 页把知情同意、素材用途、权限和销毁放在功能入口之前。
- 适老模式同时覆盖字号、按钮、对比度和减少动效，不只是主题换色。

### Android 实现时需要修正

- `county-detail` 与树/花/草葬详情标题存在残留的 `">` 字符，不能复制到 APP。
- 个别页面混用 Emoji、内联图标和文字符号，Android 统一使用 Material Symbols；服务照片继续使用现有生成素材。
- `#8A908B` 在暖白背景上的小字号对比度偏弱，正文级元数据应加深，并在适老模式再次验证。
- 纪念空间的“删除”按钮视觉权重过高；改为次级危险操作并弹出确认对话框。
- 页面路由数量显著增加，应按共享模板实现，避免为 46 个状态建立 46 套重复组件。
- Demo 的假时间、假手机号、政策金额和预约编号在 APP 中统一增加“演示数据”语义，不得造成真实办理错觉。

## 视觉验收规则

- 使用 Pixel 7 API 36，按 `375 x 812dp` 参考画布逐屏比对。
- 普通和适老模式各执行一次关键演示流；不允许文字截断、按钮移位和底栏遮挡。
- 重点比对背景、卡片圆角、间距、图片裁切、标题层级、选中态和底部安全区。
- TalkBack 能读出图片意义、Tab 状态、分段选择、开关状态和危险操作。
- 截图基线至少覆盖本次审计的 16 个关键状态。
