# 渝安青澜 2.0.0

本版本完成 App 2.0 体验优化，并完整保留 1.2.0 的 AI 照片成片追忆能力。

## 新增与优化

- 树洞人间/生灵双池各扩充至 10 封温和留言，增加虚构昵称、非实名 ID 和写信时间。
- 点灯、叶片、花朵轻回应动画，支持节流、TalkBack 播报和低动态降级。
- 人类与宠物纪念档案支持仅年份、年月或完整日期，含闰年、未来日期和先后顺序校验。
- 首页轮播遮罩按素材亮度调整；园区出入口增加高辨识颜色、门形图标和语义标签。
- 个人中心收纳为单行“版权及授权情况”入口，详情页展示完整版权、License、赛事授权与中英文授权书。
- 保留 AI 照片成片的伦理门、播放、保存和永久销毁流程。

## 兼容与质量

- 旧纪念档案 JSON 与本地快照可继续读取，人/宠、树洞双池隔离保持不变。
- DataStore 升级至 1.2.1，并增强 Windows JVM 持久化测试的稳定性。
- 38 个单元测试套件、246 个用例全部通过。
- `lintDebug`、`lintVitalRelease` 与 `assembleRelease` 通过。
- Pixel 7 API 36 上 15 个 Compose UI 测试全部通过。

> 当前 Release APK 使用项目既有调试证书签名，可直接侧载安装；应用商店上架前需替换正式发布证书。
