# 渝安青澜产品基线

## 版本裁决

现有材料形成了三个阶段：项目申报材料提供背景和调研依据，Word 方案给出详细功能，参考 Demo 则完成了人宠双轨与 5-Tab 重构。工程实现以参考 Demo 为最新版本；较早材料中的业务细节可复用，但与最新伦理边界冲突的功能不进入 APP。

不采纳的早期设想包括：4-Tab 导航、公开高赞排行、思念成长值、周年或忌日强提醒、开放式社区、江河动态主题及重庆内河江葬入口。

## 产品定位

APP 是一个可离线演示的 Android 前端原型。它用可信的本地数据串联生态安葬选择、办理进度、点位导航、私人追忆、匿名情绪陪伴和个人设置，让评审能够在一台手机上理解完整产品愿景。

所有机构、政策金额、人物、订单、纪念馆、点位和社区内容均需标注或设计为演示数据，避免被误认为真实服务承诺。

## 一级信息架构

| Tab | 核心任务 | 人宠双轨要求 |
| --- | --- | --- |
| 首页 | 品牌总览、服务入口、智能匹配、政策与活动 | 葬式入口提供人类/宠物切换 |
| 安葬 | 葬式选择、详情、套餐、订单、导航 | 顶部双轨切换；宠物无害化前置、无民政补贴、场地隔离 |
| 追忆 | 纪念馆、生命故事、日记、AI 流程、代祭 | 人类与宠物纪念空间的数据隔离 |
| 树洞 | 匿名发布与随机拾取 | 人间树洞与生灵树洞内容池隔离 |
| 我的 | 订单、纪念空间、素材、设置 | 提供树洞总开关、权限与举报管理 |

## 关键演示链路

1. 启动页进入首页，在人类与宠物入口间切换。
2. 从安葬页展示人类树葬，再切换宠物树葬，体现服务与规则差异。
3. 从追忆页进入私人纪念馆、生命故事和思念日记，再展示 AI 伦理前置。
4. 从树洞选择页分别进入人间与生灵树洞，展示内容池隔离和轻回应。
5. 在个人中心切换适老模式、树洞总开关和隐私权限。

## 伦理与合规底线

- 人类与宠物的线下场地、线上数据和树洞内容池三重隔离。
- 树洞拒绝社交化：无粉丝、无私信、无楼中楼、无点赞计数、无热度排行。
- AI 追忆不是复活，仅限授权亲属私人访问；不提供实时对话；素材用途透明且可永久销毁。
- 线上追忆是线下祭扫的补充，不替代传统仪式。
- APP 只展示预约与流程，真实业务由合规机构承接。
- 不展示重庆内河撒江服务；政策和价格全部使用演示标识。
