# 渝安青澜 1.2.0

本版本为追忆体验增加“照片成片”能力。用户完成 AI 伦理与素材授权确认后，可在母亲纪念空间中选择照片成片，经过素材检查、动态方式选择与生成阶段，观看由授权照片生成的动态追忆影像。

## 新增

- AI 追忆工作台新增“影像修复 / 照片成片”切换。
- 一张授权正面照片可进入四阶段成片流程，并获得约 17 秒的方形动态影像。
- 视频播放器支持封面、播放/暂停、控制层自动收起、声音开关和播放时间。
- 成片支持保存到本机、重新生成与永久销毁。

## 隐私与伦理

- 结果持续标明“AI 合成影像”，并说明其并非真实拍摄记录。
- 伦理与授权确认不可跳过，素材和结果保存在应用私有目录。
- 母亲照片与成片不会用于其他人物或宠物纪念空间。
- 永久销毁会清除本次会话影像及对应本机保存副本。

## 验证

- 30 个单元测试套件、182 个用例全部通过。
- `lintDebug`、`assembleDebug`、`assembleRelease` 通过。
- Pixel 7 API 36 已完成伦理门、生成、播放、声音、保存和销毁流程巡检。
